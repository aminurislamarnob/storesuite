# StoreSuite User Documentation

Welcome to the StoreSuite guide. StoreSuite gives you a clean, modern **frontend dashboard** for your WooCommerce store, so you (and your team) can manage everything — products, orders, coupons, analytics, and more — without ever touching the WordPress admin.

These guides are written for shop owners and shop managers. Each one walks through a section of the dashboard with screenshots, so you can follow along on your own store.

## Where to Start

New to StoreSuite? Start with the [Dashboard Home](dashboard-home/dashboard-home.md) to get oriented, then jump to [Products](products/products.md) and [Orders](orders/orders.md) — the two things you'll use every day.

Setting up StoreSuite for the first time (or handing it to your team)? Read [StoreSuite Settings](settings/settings.md) first to choose your dashboard page, add your branding, and lock down admin access.
